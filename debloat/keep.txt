# 保护名单 —— 任何 profile 都不允许删除这些包
#
# 03_debloat.sh 的行为是：先把 profile 选中的集合算出来，再和本文件求交集；
# 只要有交集就 **报错退出**（exit 3），而不是"跳过并继续"。
# 这样 debloat/packages.txt 里手滑写错一行，不会变成一次静默的 bootloop 构建。
#
# 这些包一旦缺失，后果不是"少个功能"，而是开机进不去或者权限体系崩掉。
